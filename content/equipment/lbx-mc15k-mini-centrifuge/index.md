## What is it?

A benchtop mini centrifuge for microtubes.

**Reference:** MCEN-15K-001 · **Model:** MC15K · **Supplier:** Labbox.

**Manufacturer / brand:** LBX Instruments (brand; OEM not identified).

## Main capabilities

Centrifugation with selectable rotational speed, relative centrifugal force and run time.

## Main specifications

Technical datasheet PDS-455, revised **10 September 2025**. Rotor configuration is a catalogue specification, not a physical check of our unit.

| Parameter | Specification |
|---|---|
| Maximum speed | 15,000 rpm; 100 rpm steps |
| Maximum RCF | 15,100 × g; 100 × g steps |
| Speed accuracy | ±20 rpm |
| Documented standard rotor | MCEN-A05-001; 12 positions for 1.5 / 2.0 mL tubes |
| Smaller tube formats | 0.2 / 0.5 mL require additional adapters; not confirmed locally |
| Timer | 30 seconds–99 minutes; continuous HOLD |
| Dimensions | Unresolved: 140 × 250 × 245 mm (Spanish) / 140 × 255 × 245 mm (English) |
| Power supply | 200–240 V, 50–60 Hz |

**Documentation discrepancies / limits:** The same datasheet disagrees between languages on one dimension; neither value is silently selected. The manual lists L255 × W245 × H140 mm and a different supply range, 110–240 V. Verify the actual rotor, tube compatibility and nameplate with the supervisor.
